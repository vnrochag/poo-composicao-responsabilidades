# Regras da atividade

- Trabalhe somente em `pratica/02-compor-estacao`.
- Não altere `tests/`, `Makefile` ou `.github/`.
- Preserve `SensorTemperatura` como baseline do capítulo anterior.
- Faça pelo menos um commit por checkpoint.
- Abra pull request para a `main` do próprio fork.
- Mantenha somente `origin` apontando para o fork; não configure `upstream` nem envie PR ao repositório-base.
- Registre uso ou não uso de IA em `AI_LOG.md`.
