# Registro de uso de IA

## Uso 1 — Ajuste da branch para a entrega

- **Pedido feito ao agente:** conferir se o trabalho estava seguindo corretamente a sequência de entrega indicada no roteiro.
- **Sugestão aceita ou rejeitada:** sugestão aceita.
- **Alteração realizada pelo estudante:** depois que identifiquei que o trabalho estava na `main` em vez da branch solicitada pelo roteiro, eu criei a branch `pratica/02-compor-estacao` a partir do estado atual do projeto e fiz o push para o GitHub.
- **Justificativa técnica:** a branch exigida pelo roteiro deveria ter o trabalho final antes da abertura do Pull Request. Como o código já estava concluído e validado, foi possível criar a nova branch sem refazer as alterações.
